# Typefaces used by the reel
All fetched from the google/fonts repository (SIL Open Font License 1.1 / Apache 2.0).
Run `./fetch_fonts.sh` in this directory to download them before rendering.

| file | family | license | role in the reel |
|---|---|---|---|
| Archivo[wdth,wght].ttf | Archivo (variable) | OFL 1.1 | hero kinetic type — weight + width axes animated per frame |
| Anton-Regular.ttf | Anton | OFL 1.1 | scene titles, particle attractor word |
| ArchivoBlack-Regular.ttf | Archivo Black | OFL 1.1 | "KINETIC" block word |
| SpaceGrotesk[wght].ttf | Space Grotesk (variable) | OFL 1.1 | secondary UI type |
| Syne[wght].ttf | Syne (variable) | OFL 1.1 | alt display |
| IBMPlexMono-Bold.ttf / -SemiBold.ttf | IBM Plex Mono | OFL 1.1 | HUD, labels, timecode |
| DMMono-Regular.ttf | DM Mono | OFL 1.1 | timecode alt |
| IBMPlexSansCondensed-Bold.ttf | IBM Plex Sans Condensed | OFL 1.1 | fallback labels |
| BebasNeue-Regular.ttf | Bebas Neue | OFL 1.1 | alt display |
