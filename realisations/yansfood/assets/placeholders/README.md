## 🔒 Règles de Non-Invention
1. Aucun faux restaurant ni code postal américain. Les commandes et interfaces reflètent l'offre réelle (Douala / Yaoundé, Poulet DG, Jollof Rice, montants en FCFA).
2. Promesse de marque obligatoire et approuvée : **« TON REPAS, SANS LA FILE. »**
3. Boucle parfaite : **F000 = F900** à 60 fps (15,00 s à 120 BPM).
