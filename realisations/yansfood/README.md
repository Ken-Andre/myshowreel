## ⚙️ Pipeline d'Export Playwright & FFmpeg

1. **Capture déterministe frame-par-frame (Playwright) :**
   ```bash
   node render_playwright.js --url "http://localhost:8080/realisations/yansfood/index.html" --frames 900 --fps 60 --out "./frames"
   ```
2. **Normalisation de la musique à -14 LUFS :**
   ```bash
   ffmpeg -i music.mp3 -af loudnorm=I=-14:LRA=11:TP=-1.5 -ar 48000 music-norm.mp3
   ```
3. **Encodage Master H.264 yuv420p 60 fps + Audio AAC :**
   ```bash
   ffmpeg -r 60 -i ./frames/frame_%04d.png -i final_audio_mix.wav \
          -c:v libx264 -pix_fmt yuv420p -profile:v high -level 4.2 -crf 17 \
          -c:a aac -b:a 320k -shortest \
          videos/yansfood_master_1440x1440_60fps.mp4
   ```
4. **Déclinaisons :**
   - **Social 1080×1080 @ 30 fps :** `ffmpeg -i videos/yansfood_master_1440x1440_60fps.mp4 -vf "scale=1080:1080,fps=30" -c:v libx264 -crf 19 -c:a aac -b:a 256k videos/yansfood_social_1080x1080_30fps.mp4`
   - **Vertical 1080×1920 (9:16 Story/Reels) :** `ffmpeg -i videos/yansfood_master_1440x1440_60fps.mp4 -vf "scale=1080:1080,pad=1080:1920:0:420:color=0x0A0A0A" -c:v libx264 -crf 18 -c:a copy videos/yansfood_vertical_1080x1920.mp4`
